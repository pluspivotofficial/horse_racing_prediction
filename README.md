# 🐎 TURF ORACLE

### 週末JRAの勝ち馬を、データで撃ち抜く。AI競馬予想プラットフォーム

過去戦績・騎手相性・コース/距離/馬場/天候適性まで **11ファクター** を多角分析し、
勝率・推奨馬券・「なぜ買えるのか」の根拠コメントを毎レース自動生成します。

## これは何？

月曜〜金曜の平日に、**その週末に行われるJRAの出走レース**を netkeiba の実データから洗い出し、
各馬の過去の全レース履歴を解析して予想を組み立てるプラットフォームです。

- 🎯 **多角的な適性分析** — 近走成績・クラス実績・距離/コース/馬場/天候適性・騎手相性・脚質・枠順・馬体を個別スコア化
- 🗣️ **5人のAIアナリストが解説** — データ分析官／展開ラボ／相性ウォッチャー／妙味ハンター／リスク番人が、それぞれの視点でコメント
- 💰 **推奨馬券を自動生成** — 単勝・複勝・ワイド・馬連・3連複フォーメーションを、期待値(EV)とケリー基準で提案
- ⚠️ **足りないデータを正直に申告** — オッズ未発売・馬場未確定・実績薄などを毎レース明示
- 🎨 **遊び心のあるビジュアル** — "ターフナイト" テーマのダッシュボード（ライト/ダーク対応）

### 実データでのバックテスト（2025/06/28-29・20レース）

| 指標 | 結果 |
|---|---|
| ◎（本命）複勝的中率 | **70%**（14/20R が3着内）|
| ◎ 単勝的中率 | 15%（3/20R）|
| ◎ 単勝フラットベット回収率 | **154%** |

> 例: 函館11R 青函S では、市場12番人気（25.8倍）の **エーティーマクフィ** をモデルが◎に指名 → **1着**。
> コース適性(函館 複勝率100%)と上がり最速の決め手を根拠に、市場が見落とした妙味を捉えました。

## 使い方

### 1. 予想データを生成（Python）

```bash
pip install -r engine/requirements.txt

# 今週末を予想（平日ワークフロー: 今日を起点に直近の土日を対象）
python scripts/predict_weekend.py --today 2026-07-06

# 特定の週末を明示指定（例: デモに使った2025年6月末）
python scripts/predict_weekend.py --dates 20250628 20250629 --min-race-no 9 --max 20

# 主要レースのみ / オフライン(キャッシュ)で再実行
python scripts/predict_weekend.py --dates 20250628 --grade-only --offline
```

出力は `data/output/weekend_<date>.json` と `web/public/data/weekend.json` に書き込まれます。

### 2. すぐ見る（インストール不要）

`web/showcase/turf_oracle.html` をブラウザで開くだけ。実データを埋め込んだ自己完結デモです。

### 3. Webアプリを起動（Next.js）

```bash
cd web
npm install
npm run dev        # http://localhost:3000
```

## 予想ロジックの要点

各馬について、過去の全出走履歴から下記を**個別に**スコア化（0–100, 50=中立/データ不足）します。
小サンプルの条件別成績は、その馬の総合力へ向けて**縮約(shrinkage)**し過剰反応を防ぎます。

| ファクター | 見るもの |
|---|---|
| 近走成績 | 直近走の着順（相対化）と上昇度、複勝率 |
| クラス実績 | 当該格以上での経験と最高着順 |
| 距離適性 | ±200m帯での成績 |
| コース適性 | 同一競馬場での成績 |
| 馬場/馬場状態/天候適性 | 芝ダ・良稍重不・晴雨での成績 |
| 騎手相性 | その馬×今回騎手のコンビ成績、乗り替わり検出 |
| 脚質・決め手 | 通過順から脚質推定＋上がり3F最速 |
| 枠順 | 距離/馬場に応じた内外の有利不利 |
| 馬体・調子 | 馬体重増減・使用間隔(ローテ) |

合成能力値を **softmax** で勝率に、**Harville近似** で複勝率に変換。市場オッズと突き合わせて
`期待値 = 勝率 × オッズ` を算出し、+EVの馬券を推奨します。

> 詳細は [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) を参照。
